# CreditLens delivery scope

Build an end-to-end consumer lending analytics platform with:

1. Validated multi-table ingestion; Bronze, Silver, and Gold layers; lineage and quality reports.
2. Portfolio KPIs, segment event rates, confidence intervals, and historical credit behavior.
3. PostgreSQL SQL analyses with joins, windows, conditional aggregates, indexing, and materialized views.
4. Statistical analysis with explicit uncertainty and observational limitations.
5. Disjoint training, calibration, validation, and test sets; probability estimation, ROC-AUC, average precision, Brier score, calibration and subgroup diagnostics.
6. Hypothetical risk-threshold lending simulation.
7. A working web analytics interface and Power BI integration materials.
8. Reproducible local execution, containers, CI, and documented operational limitations.

Source: the user's pasted CreditLens brief. Planned extensions include dbt, Prefect, Redis, boosted trees, SHAP, monitoring, and deployment. Mark these as future work until implemented and verified.

The demonstration must clearly identify synthetic data and must not present generated metrics as real Home Credit findings. Never infer actual credit losses or profit without defensible assumptions and supporting data.
